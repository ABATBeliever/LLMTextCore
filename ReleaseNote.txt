LLMTextCore Release Notes
=========================


------------------------------------------------------------------------
v0.7.5
------------------------------------------------------------------------

- [EXE] システムプロンプトを指定できるようにした。


------------------------------------------------------------------------
v0.7.4
------------------------------------------------------------------------
Bug fixes / Concurrency

- [DLL] 出力の改行コードをCRLFに統一

- [DLL] 利用するllama.cppのバージョンを固定

- [DLL] 同期APIと非同期APIの同時実行によるデータ競合を修正。
  「開始条件の判定」と「BUSYへの変更」をアトミックに行う try_start_generation() を
  新設し、同期・非同期どちらの入口もこれを通すようにした。
  非同期生成が実行中、またはDONE/CANCELLEDの結果が未取得の間、同期APIは
  失敗するようになった (llmtc_generate はNULL、llmtc_generate_to_buffer は
  負値を返す)。同期APIのみ、または非同期APIのみを使う通常の利用では
  挙動に変化はない。

- [DLL] llmtc_generate_async のステータス判定に残っていたTOCTOUレースを修正。
  compare_exchangeによるCASループに置き換えた。エラーコード(-1/-2/-4)に変更はない。

- [DLL] g_last_error が生成のたびに際限なく蓄積する問題を修正。
  生成呼び出しの先頭で毎回クリアするようにし、防衛的にログ側にもサイズ上限(4KB)を追加した。

- [DLL] llmtc_free が生成完了まで無期限にブロックする問題を修正。
  呼び出し時に内部でキャンセルフラグを立ててから join するようにした。


------------------------------------------------------------------------
v0.7.3
------------------------------------------------------------------------
Bug fixes / Security

- [DLL] 生成ループのダングリングポインタを修正 (ループ内ローカル変数をループ外に移動)

- [DLL] llama_chat_apply_template の2回目呼び出し結果の未チェックを修正
  (失敗時に負値がstd::stringへ渡りメモリ破壊が起きる可能性があった)

- [DLL] llmtc_init に model_path のNULLチェックを追加 (エラーコード-1を返す)

- [DLL] llama_backend_free の二重呼び出しを g_backend_initialized フラグで防止

- [DLL] llmtc_get_result_to_buffer にBUSY中の呼び出しガードを追加
  (ステータスを強制的にIDLEへ戻してしまう問題を修正、BUSY中は-3を返す)

- [DLL] llmtc_generate_async にDONE/CANCELLED状態のガードを追加
  (前の結果が無言で消える問題を修正、-4を返す)

- [DLL] llmtc_generate_async のステータス二重ロードを1回に修正

- [DLL] llmtc_free の g_async_result.clear() に g_result_mutex を追加

- [DLL] n_tokens <= 0 のチェックを追加 (トークナイズ結果が空の場合に早期return)

- [DLL] llama_sampler_init_penalties を正しい5引数シグネチャに修正。
  これによりpenalty_last_nが実際に機能するようになった。

- [DLL] ビルド時のC4005警告 (LLMTEXTCORE_EXPORTSマクロ再定義) を修正

- [EXE/CLI] wide_to_utf8 / utf8_to_sjis のmalloc戻り値NULLチェックを追加

- [EXE/CLI] print_encoded のutf8_to_sjis結果NULLガードを追加

- [EXE/CLI] argv (uargv) のメモリリークを修正 (goto cleanupパターンで確実に解放)

v0.7.1
------------------------------------------------------------------------
Bug fixes / Reliability

- [DLL/EXE] 二重初期化ガードを追加。
  llmtc_free を呼ばずに llmtc_init を再度呼んだ場合、-3 を返して処理を中止する。

- [DLL] llmtc_get_last_error_to_buffer を追加。
  llmtc_init の失敗原因を文字列で取得できる。llmtc_init を呼ぶたびにリセットされる。

- [EXE] llmtc_init 失敗時のエラーメッセージに、上記エラー内容を付記


------------------------------------------------------------------------
v0.7.0
------------------------------------------------------------------------

- [DLL] llmtc_cancel を追加。生成中に呼ぶと、次のトークン生成前(数十ms以内)に中断する。

- [DLL] LLMTC_STATUS_CANCELLED (=3) を追加。
  キャンセル後のステータスで、DONEと同じ手順で途中結果を取得できる。

- [DLL] llmtc_set_generation_params(top_p, repeat_penalty, penalty_last_n) を追加。
  0以下を渡した引数はデフォルト値を維持する (top_p=0.95, repeat_penalty=1.0)。

- [DLL] サンプラーチェーンを刷新 (penalties → top_p → temperature → distの順で適用)

- [EXE] 引数8番目にtop_p、9番目にrepeat_penaltyを追加


------------------------------------------------------------------------
v0.6.0
------------------------------------------------------------------------

- [DLL] llmtc_get_partial_result_to_buffer を追加。
  非同期生成中(BUSY)でも呼べる。前回との差分でストリーミング表示ができる。

- [DLL] llmtc_get_model_info_to_buffer を追加 (モデル名・パラメータ数・コンテキスト長)

- [DLL] llmtc_get_n_ctx を追加

- [EXE] -i <model.gguf> オプションを追加 (モデル情報を表示して終了)

- [EXE] 引数7番目 (stream) を追加。1でトークンを逐次出力する。


------------------------------------------------------------------------
v0.5.0
------------------------------------------------------------------------

- [DLL] 非同期APIを追加。
    llmtc_generate_async  生成をバックグラウンドスレッドで開始して即リターン
    llmtc_get_status      現在の生成状態を返す (IDLE/BUSY/DONE/ERROR)
    llmtc_get_result_to_buffer  生成完了後に結果を取得

- [DLL] llmtc_set_encoding を追加。
  LLMTC_ENCODING_UTF8 (0, デフォルト) と LLMTC_ENCODING_SJIS (1) を選択できる。
  SJIS指定時は *_to_buffer 系の出力のみUTF-8→CP932に変換される (入力は常にUTF-8)。

- [EXE] 引数6番目 (encoding) を追加。1でShift-JIS出力になる。

- [EXE] コンソールのコードページを起動時にUTF-8に固定 (-h, -v等の文字化けを解消)


------------------------------------------------------------------------
v0.4.0
------------------------------------------------------------------------
基本機能が完成したため、GitHubに公開した最初のバージョン。

- [DLL] 基本APIを確立。
    llmtc_version_info / llmtc_version_info_to_buffer
    llmtc_set_verbose
    llmtc_init / llmtc_free
    llmtc_generate / llmtc_generate_to_buffer (同期、ステートレス)

- [DLL] ステートレス設計を採用。
  DLL側は会話履歴を保持せず、呼び出しのたびに1ターン完結で応答を生成する。

- [DLL] 生成パラメータ (temperature, max_tokens) を引数で指定できる。

- [EXE] 基本的なCLIを実装。
  引数: <model.gguf> [質問文] [temperature] [max_tokens] [verbose] [encoding]
  -v, --version / -h, --help / -l (ロード確認) を実装。
  標準出力にはAIの応答のみ、エラーは標準エラー出力に分離。

- [DLL/EXE] llmtextcore.def によりエクスポート名を装飾なしで固定。
  64bit HSP を含む呼び出し側から一貫した関数名でアクセスできる。

- [DLL/EXE] llama.cpp を静的リンク。
  配布物は LLMTextCore.dll + LLMTextCore.exe + .ggufモデルのみで動作する。
